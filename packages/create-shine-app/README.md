# create-shine-app

Build compact, high-performance, and secure desktop applications using a web frontend — powered by modern C++20 and React.

## Prerequisites

- **Node.js** (>= 18.x) – [Download](https://nodejs.org/)
- **npm** (shipped with Node)
- **CMake**
- **vcpkg**

---

## Installation

```bash
npm create shine-app@latest
```

Or use it directly with `npx`:

```bash
npx create-shine-app@latest
```
